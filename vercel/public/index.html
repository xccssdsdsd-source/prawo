Jak agenci AI powinni czytać prawo

Rules for AI agents

  • Zacznij od search_law z krótką frazą (2–4 słowa), nie całym pytaniem.
  • Dosłowne brzmienie weryfikuj przez get_article – wyszukiwanie zwraca tylko fragmenty.
  • Hierarchia źródeł: ujednolicone > jednolite > podstawowe (brzmienie z dnia ogłoszenia) > zmieniające (nie są źródłem obowiązującej treści).
  • Nigdy nie zgaduj numerów artykułów ani treści przepisów; cytuj tylko to, co zwróciło API.
  • Zawsze podawaj display_address, numer art., kategorię i source_url.
  • Zawsze podawaj „stan danych na dzień …” (z /data-info.json).
  • Czytaj pole warnings i przekazuj je użytkownikowi; przy truncated: true nie zgaduj reszty tekstu.
  • Brak wyniku ≠ brak przepisu – spróbuj synonimów, mniej słów, innej kategorii.
  • Gdy odpowiedź zależy od daty zdarzenia lub rodzaju stosunku, dopytaj użytkownika.
  • To nie porada prawna – aktualne brzmienie weryfikuj w ISAP (isap.sejm.gov.pl).

Jak podłączyć

Connect your client

Pełna instrukcja krok po kroku dla Claude (claude.ai, Desktop, Code, API), Gemini, ChatGPT, Cursora, VS Code i innych – z gotowymi snippetami, testem połączenia i promptem do wklejenia. Poniżej wersja skrócona.

MCP

Claude Code i inni klienci MCP (HTTP).

claude mcp add --transport http prawo-pl https://TWOJA-DOMENA.vercel.app/api/mcp

REST

Wyszukiwanie i dosłowne brzmienie artykułu.

curl -G "https://TWOJA-DOMENA.vercel.app/api/search" --data-urlencode "q=zadośćuczynienie art. 445"
curl "https://TWOJA-DOMENA.vercel.app/api/article?id=DU/1964/93&art=445"
